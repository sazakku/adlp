# ADLP

Página estática para GitHub Pages: una playa en pixel art al amanecer, un gato blanco con manchas negras y un botón que muestra **"Eres la mejor Abogada del Mundo"** en inglés, portugués, alemán, italiano, francés y japonés.

- Todo se dibuja en un `<canvas>` con JavaScript, sin imágenes externas ni dependencias.
- Tipografía: Silkscreen (Google Fonts), con DotGothic16 para el japonés.
- Se adapta a celular y escritorio y respeta `prefers-reduced-motion`.

Para verla en local basta con abrir `index.html` en el navegador.
